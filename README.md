# PhaseLiftedFIR GPU-DIC

PhaseLiftedFIR GPU-DIC is a CUDA-accelerated two-dimensional digital image correlation (2D DIC) project with direct texture, cubic B-spline, and phase-lifted FIR interpolation paths.

## Project status

This repository is the project landing page for the associated research software. The source code is currently maintained privately and will be released after the associated manuscript has been accepted.

## Scope

The software is designed for pointwise displacement measurement from grayscale image sequences and binary region-of-interest masks. The planned source release will include the CUDA implementation, build instructions, example inputs, and license information.

## Planned release contents

- CUDA solver source code;
- Windows build instructions;
- Direct texture, cubic B-spline, and phase-lifted FIR configurations;
- Small example image sets and ROI masks;
- Output-format and reproducibility documentation.
